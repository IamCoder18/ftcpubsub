# GamepadAdaptor

```java
GamepadAdaptor.attach(orchestrator, gamepad1, "g1");
```

One line. Every `boolean` field on `gamepad1` becomes a topic:

| Topic                        | Type    | Meaning                              |
| ---------------------------- | ------- | ------------------------------------ |
| `g1/<button>`                | Boolean | current state                        |
| `g1/<button>/rising`         | Boolean | fires (value=true) on 0→1 transition |
| `g1/<button>/falling`        | Boolean | fires on 1→0 transition              |

Every `float` field becomes a single topic:

| Topic         | Type   | Meaning       |
| ------------- | ------ | ------------- |
| `g1/<axis>`   | Float  | current value |

Polling is at 60 Hz (`GamepadAdaptor.java:43`, `HZ = 60`).

See `GamepadAdaptor.java:101-127` for the polling implementation. The adaptor uses reflection so it works against the real FTC SDK `Gamepad` class with no compile-time dependency.
