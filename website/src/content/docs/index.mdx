# Synapse Docs

Welcome. Synapse is a tiny pub/sub bus that gives FTC robot code a single dedicated hardware thread and typed topics for inter-module communication.

## 60-second tour

1. Add the dependency (see [Install](/install)).
2. Extend `SafeOpMode` instead of `OpMode`.
3. Build `Node`s — one concern each (drive, intake, shooter).
4. Use `@SubscribedTo`, `@RunPeriodically`, `@RunnableAction` to wire them up.
5. Anything that touches a `DcMotorEx` / `Servo` / `IMU` runs on the hardware thread.
