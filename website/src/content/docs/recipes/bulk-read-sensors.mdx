# Bulk read sensors

When several sensors need to be sampled at the same rate and their values published together, use `bulkRead`:

```java
@TeleOp(name = "Telemetry")
public class Telemetry extends SafeOpMode {
    @Override protected void onSafeInit() {
        hardware.bulkRead(50, view -> {
            // All of this runs on the hardware thread.
            SafeDevice<DcMotorEx> intake = safeMap.device(DcMotorEx.class, "intake");
            intake.call(m -> {
                view.publish("intake/amps", m.getCurrent(CurrentUnit.AMPS));
                view.publish("intake/pos",  m.getCurrentPosition());
                return null;
            });
        });
    }
}
```

The 50 Hz loop guarantees consistent sampling — both values in this tick reflect the same instant on the bus.

See `HardwareActions.java:141-170` for the `bulkRead` reference.
