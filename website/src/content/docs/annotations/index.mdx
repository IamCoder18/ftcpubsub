# Annotations

- **[@SubscribedTo](/docs/annotations/subscribed-to)** — react to a topic.
- **[@RunPeriodically](/docs/annotations/run-periodically)** — fire on a fixed-rate loop.
- **[@RunnableAction](/docs/annotations/runnable-action)** — register a named, fire-on-demand action.
- **[@OnHardwareThread](/docs/annotations/on-hardware-thread)** — reroute a callback onto the single hardware thread.
