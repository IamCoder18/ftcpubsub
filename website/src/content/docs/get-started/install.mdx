# Install

Synapse publishes to GitHub Packages at `https://maven.pkg.github.com/IamCoder18/synapse`. You must add that repository and authenticate before Gradle or Maven can resolve `com.aaravlabs:synapse:0.3.1`. The token needs only the `read:packages` scope.

## Step 0 — Configure credentials

Put these in `~/.gradle/gradle.properties` (do **not** commit them):

```properties
githubUser=<your-github-username>
githubToken=ghp_your_token_here
```

For Maven, set the same values as **environment variables** so the `<settings>` server entry below can read them:

```bash
export GITHUB_USER=<your-github-username>
export GITHUB_TOKEN=ghp_your_token_here
```

Either form satisfies GitHub Packages' `read:packages` requirement.

## Step 1 — Add the repository + dependency

### Gradle (Groovy)

```gradle
repositories {
    mavenCentral()
    google()
    maven {
        url = uri("https://maven.pkg.github.com/IamCoder18/synapse")
        credentials {
            username = findProperty("githubUser") ?: System.getenv("GITHUB_USER") ?: System.getenv("GITHUB_ACTOR")
            password = findProperty("githubToken") ?: System.getenv("GITHUB_TOKEN")
        }
    }
}

dependencies {
    implementation 'com.aaravlabs:synapse:0.3.1'
}
```

### Gradle (Kotlin DSL)

```kotlin
repositories {
    mavenCentral()
    google()
    maven {
        url = uri("https://maven.pkg.github.com/IamCoder18/synapse")
        credentials {
            username = (findProperty("githubUser") as String?)
                ?: System.getenv("GITHUB_USER")
                ?: System.getenv("GITHUB_ACTOR")
            password = (findProperty("githubToken") as String?)
                ?: System.getenv("GITHUB_TOKEN")
        }
    }
}

dependencies {
    implementation("com.aaravlabs:synapse:0.3.1")
}
```

### Maven

```xml
<settings>
  <servers>
    <server>
      <id>github-synapse</id>
      <username>${env.GITHUB_USER}</username>
      <password>${env.GITHUB_TOKEN}</password>
    </server>
  </servers>
</settings>

<!-- in your pom.xml -->
<repositories>
  <repository>
    <id>github-synapse</id>
    <url>https://maven.pkg.github.com/IamCoder18/synapse</url>
  </repository>
</repositories>

<dependency>
    <groupId>com.aaravlabs</groupId>
    <artifactId>synapse</artifactId>
    <version>0.3.1</version>
</dependency>
```

## R8 / ProGuard

Synapse ships its keep rules inside the JAR at `META-INF/proguard/synapse.pro`, so minification is safe with no extra config. See [`SafeOpMode.java`](https://github.com/IamCoder18/synapse/blob/main/src/main/java/com/aaravlabs/synapse/ftc/SafeOpMode.java) and the build script.

## What you get

- A 40 KB JAR with zero runtime dependencies.
- The orchestrator, all four annotations, `HardwareActions`, `SafeDevice`, `SafeHardwareMap`, `GamepadAdaptor`, and `SafeOpMode`.

See [First OpMode](/docs/get-started/first-opmode) for the next step.
