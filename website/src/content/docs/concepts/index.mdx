# Concepts

- **[Orchestrator](/docs/concepts/orchestrator)** — The bus. Owns topics, nodes, and the three thread pools.
- **[Topics](/docs/concepts/topics)** — Named, typed channels. The unit of communication.
- **[Nodes](/docs/concepts/nodes)** — Independent units of code that subscribe, publish, or run periodic work.
- **[Subscriptions](/docs/concepts/subscriptions)** — How a node receives values, in three styles.
